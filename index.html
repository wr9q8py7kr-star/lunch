🔗 วิธีตั้งค่า Cloud Sync (Google Sheet)

  1. เปิด sheets.new → สร้าง Sheet ใหม่
  2. เมนู Extensions → Apps Script
  3. ลบโค้ดเดิม → วางโค้ด Code.gs
  4. กด Deploy → New deployment
  5. Type: Web app · Execute as: Me · Who has access: Anyone
  6. Deploy → Authorize → Allow
  7. Copy Web app URL → วางในหน้า ⚙️ ตั้งค่าโครงการ

📱 การใช้งานบนมือถือ

  • แตะปุ่ม ☰ มุมซ้ายบนเพื่อเปิดเมนู
  • ตารางอาหารใช้การ์ด — แต่ละวันเป็น 1 การ์ด
  • แก้ไขเมนูได้ 2 ทาง: หน้า 📅 ตารางอาหาร หรือหน้า 📋 ส่งมอบงาน
